# CPGE TSIAT - Android APK (built for free in the cloud)

1. Create a free account at https://github.com
2. Click + > New repository (any name, e.g. cpge-tsiat). Public or private is fine.
3. Click "uploading an existing file" and drag in EVERYTHING from this folder,
   including the hidden ".github" folder, the "www" folder, package.json,
   capacitor.config.json and .gitignore. Click Commit.
4. Open the "Actions" tab. The "Build APK" job starts by itself (takes ~5 minutes).
   If it does not, click "Build APK" > "Run workflow".
5. When it shows a green check, open it and download "CPGE-TSIAT-apk" at the bottom.
   Unzip it: inside is app-debug.apk.
6. Send app-debug.apk to friends on WhatsApp. On their phone: open it and allow
   "Install unknown apps" when Android asks.
